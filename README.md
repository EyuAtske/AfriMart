# AfriMart

AfriMart is an e-commerce platform being developed as an internship project.

The project allows users to browse products, manage carts, place orders, and manage shops and products.

## Current Progress

### Completed

* Project setup and architecture
* User registration and login
* JWT authentication and protected routes
* User roles
* Shop creation and management
* Shop ownership and authorization
* Product categories and subcategories
* Product creation and management
* Product validation
* PostgreSQL database setup
* Cart development
* Order development
* Backend testing
* Logging and distributed tracing
* Grafana monitoring

### Currently Working On

* Cart and checkout
* Orders and seller order management
* Payment integration
* Completing Phase 1 testing

### Planned

* Payment integration
* AI shopping assistant
* Analytics
* Further system improvements

## Project Structure

The project has two main applications:

* **Frontend** — Nuxt
* **Backend** — Go

The backend contains modules for authentication, shops, products, carts, orders, and payments.

## Tech Stack

* Go
* PostgreSQL
* Nuxt
* Docker
* RabbitMQ
* OpenTelemetry
* Grafana
